Mono3D – Single Image Depth Estimation

Mono3D is a Python-based project that estimates depth from a single 2D image using a pretrained Depth Anything V2 model.

Features

- Estimates relative depth from an image.
- Generates grayscale depth maps and color heatmaps.
- Creates threshold-based depth masks.
- Saves the generated visualizations as images.

Technologies Used

Python, Google Colab, PyTorch, Hugging Face Transformers, NumPy, Pillow, Matplotlib, and Depth Anything V2.

How to Run

1. Open the notebook in Google Colab.
2. Run the code cells in order.
3. Upload an input image when prompted.
4. View and save the generated depth visualizations.

Applications

Potential applications include scene understanding, image analysis, robotics, and 3D vision research.

Limitations

The estimated depth is relative, not guaranteed to represent accurate real-world distances.
